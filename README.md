# Portfólio Pessoal — Marciele Lopes

Este projeto foi desenvolvido como parte do Challenge Front-End Iniciante.

O objetivo é criar um portfólio profissional online para apresentar minha formação, habilidades e projetos de forma clara, organizada e interativa.

Sou estudante de Tecnologia em Análise e Desenvolvimento de Sistemas pela UNIMAR, atualmente no 6º módulo, e participo da Residência Full Stack 5.0 do Instituto de Pesquisas ELDORADO.

## Tecnologias utilizadas

Este projeto foi desenvolvido utilizando:

- HTML5 — estrutura e organização do conteúdo.
- CSS3 — estilização, layout e responsividade.
- JavaScript — interações e exibição de resultados.
- Git — controle de versão.
- GitHub — armazenamento e versionamento do projeto.
- Figma — prototipação de baixa e média fidelidade.

## Funcionalidades

O portfólio possui as seguintes funcionalidades:

- Navegação entre as seções da página.
- Apresentação das minhas informações profissionais e acadêmicas.
- Exibição das tecnologias que estou estudando.
- Apresentação dos projetos desenvolvidos.
- Botão "Ver meus projetos" com rolagem automática até a seção de projetos.
- Seleção de uma tecnologia na seção "Encontre um projeto".
- Exibição de um projeto de acordo com a tecnologia escolhida pelo usuário.
- Links para GitHub e LinkedIn.
- Layout responsivo para diferentes tamanhos de tela.

## Como a interface apoia a decisão do usuário

A interface permite que o visitante escolha uma tecnologia de seu interesse.

A partir dessa escolha, o JavaScript apresenta um projeto relacionado à tecnologia selecionada, facilitando a navegação e ajudando o usuário a decidir qual projeto deseja conhecer.

Além disso, o portfólio organiza as informações em seções claras, permitindo que o visitante conheça minha formação, habilidades, projetos e formas de contato.

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Navegue pelas seções e teste as funcionalidades do portfólio.
